# Python for Data Engineering: AI Tutor Guide

A free, open guide for learning Python and SQL for cloud data engineering.
16 topics. Each one defines exactly what is enough, and gives you a prompt
to learn it with any AI tutor (Claude, ChatGPT, Gemini).

**Live guide → [mcnusair.github.io/python-for-de-ai-tutor](https://mcnusair.github.io/python-for-de-ai-tutor)**

## What is inside

- 16 topics covering Python, SQL, and essential tools for DE
- For each topic: a "what is enough" checklist so you never over-learn
- A copy-ready AI tutor prompt that turns any AI into a strict, DE-focused tutor
- Progress tracker that saves in your browser
- Filter by Python, SQL, or Tools, or show only topics not done yet
- Dark mode, fully responsive

## Topics covered

**Python** : Functions, Exception handling, File I/O, OOP, Logging,
Virtual environments, Secrets management, Modules, Type hints,
Unit testing, pandas, requests

**SQL** : DuckDB, Advanced SQL (window functions, regex, CTEs, pivots)

**Tools** : Git, Bash & command line

## Who this is for

Engineers, Junior data engineers and analysts transitioning into DE who want a
clear, opinionated answer to "what do I actually need to learn in Python and how
much is enough?" without falling into the tutorial trap and getting stuck forever in Python.
Some very basic programming knowledge is required. Basic SQL is optional for the DuckDB part.

## How to use it

1. Open the live guide
2. Click a topic to expand it
3. Read the "what is enough" checklist
4. Copy the AI tutor prompt and paste it into any AI
5. Work through the session until you complete the final exercise
6. Check the topic as done and move to the next one

## Tech

Single self-contained HTML file. No framework, no build step, no server.
Progress saves to localStorage. Works offline after first load.
